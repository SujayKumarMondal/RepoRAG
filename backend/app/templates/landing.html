Why RepoRAG?

Traditional chatbots understand documents. RepoRAG is designed to understand software systems.

🧠

Codebase Understanding

Ask questions about architecture, authentication, APIs, services, database operations and execution flows.

🔗

Dependency Intelligence

Understand relationships between files, modules, classes, functions and services through a dependency graph.

🎯

Context-Aware RAG

Retrieve relevant code using semantic, lexical and structural signals instead of relying on vector similarity alone.

Why RAG?

A repository can contain thousands of files and millions of tokens. Sending the entire codebase to an LLM is expensive, slow and unreliable. RAG retrieves only the most relevant context.

Core Capabilities

RepoRAG combines multiple software-analysis techniques into a single backend intelligence layer.

📦

Repository Ingestion

Clone and analyze GitHub repositories, discover files and prepare them for code intelligence processing.

🌳

AST-Aware Parsing

Parse source code into meaningful symbols, classes, methods, functions and imports instead of arbitrary text chunks.

🕸️

Dependency Graph

Build relationships between modules, files, symbols and services to understand how the system is connected.

🔎

Hybrid Search

Combine vector similarity, lexical search, symbol matching and dependency information to retrieve relevant code.

🤖

AI Code Assistant

Ask natural-language questions about architecture, implementation details, flows and potential issues.

📍

Source Citations

Answers can reference exact files, symbols and line ranges so developers can verify the generated explanation.

API Surface

The backend exposes a structured REST API for repository ingestion, analysis, and graph exploration.

GET /api/v1/auth/github/login GitHub OAuth
GET /api/v1/repositories List repositories
POST /api/v1/repositories Add repository
POST /api/v1/repositories/{id}/ingest Start ingestion
GET /api/v1/repositories/{id}/graph Dependency graph
